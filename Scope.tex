\section{SCOPE}

\begin{enumerate}[(a)]
	\item \textbf{\underline{General:}} This document describes the requirements and verification processes for the Tri-Mic.  The Tri-Mic is a 3D direction-finding microphone that uses three mics in a triangular array to figure out where sounds are coming from.  It runs the MUSIC algorithm to pinpoint direction in three dimensions.  The device is built for field technicians and hardware people who need to locate sound sources without moving to a separate workstation.  The user can steer the directional focus with a physical control and see the results on a built-in spectrogram display.  Captured data can be exported to a PC for further analysis.

	\end{itemize}
\end{enumerate}
